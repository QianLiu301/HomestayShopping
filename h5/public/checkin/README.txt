住宿登记页示例图片目录
====================

请把示例图放到本目录,文件名必须为:

1. passport-sample.png       — 护照信息页示例图(选"外国人护照"时显示)
2. hkmo-permit-sample.png    — 港澳居民来往内地通行证示例图(选"港澳通行证"时显示)
3. taiwan-permit-sample.png  — 台湾居民来往大陆通行证示例图(选"台湾通行证"时显示)
4. handheld-sample.png       — 手持证件照片示例图(所有证件类型共用,不变化)

放好后重新构建 h5 (npm run build) 即可生效。
也可以直接把图片上传到已部署网站根目录的 checkin/ 文件夹,立即生效。
未放置图片时,页面会显示 🛂 / 🤳 表情符号占位,不影响功能。
